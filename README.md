# Домашнее задание к работе 4

# Условие задачи: Чтобы открыть портал, необходимо зажечь три древних кристалла. Кристалл загорается, если переданная ему энергия (A, B, C) кратна трем. Портал откроется только если загорятся все три кристалла. Запишите условие открытия портала.

# 1. Алгоритм и блок-схема

Алгоритм:
1. Начало.
2. Объявить переменные:
	 A, B, C — целые числа для хранения энергии кристаллов.
	 portal_opened — логическая переменная (флаг) открытия портала.
3. Считать с клавиатуры значения A, B и C.
4. Вычислить общее условие открытия портала (логическое И):
	 portal_opened = (A % 3 == 0) AND (B % 3 == 0) AND (C % 3 == 0)
5. Вывести результаты вычислений для каждого кристалла и итоговое состояние портала.
6. Конец.

# 2. КОД
```c   
#define _CRT_SECURE_NO_WARNINGS

#include <stdio.h>

#include <locale.h>

int main() {

    setlocale(LC_ALL, ".UTF8");

    int A, B, C;
    int portal_opened;

    printf("=== СИСТЕМА АКТИВАЦИИ ПОРТАЛА ===\n");
    printf("Введите три целых числа через пробел (энергия A, B, C): ");
    scanf("%d %d %d", &A, &B, &C);

    
    if (A % 3 == 0 && B % 3 == 0 && C % 3 == 0) {
        portal_opened = 1; 
    }
    else {
        portal_opened = 0; 
    }
    printf("Портал открыт (1 - да, 0 - нет): %d\n", portal_opened);

    return 0;
}
```
